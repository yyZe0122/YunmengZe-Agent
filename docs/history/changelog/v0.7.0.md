# YunmengZe Agent v0.7.0

**Alpha · Pre-release**  
**Alpha · 预发布**

VS Code Webview chat (fourth peer) and `/perm similar|permanent` grants that stay inside the chat approval window.

VS Code Webview 聊天（第四 peer），以及夹进 chat approval 窗的 `/perm similar|permanent` grant。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **IDE** | VS Code V4: activity-bar session list + drag-able editor tabs talk to the local Gateway (`interactive: true`). Drag files as `@path` (outside the folder = absolute + extra-root `/perm`). Opening VS Code does **not** start `ymzd`; the first chat tab does. Closing the editor does **not** `ymz stop`. Ctrl/Cmd+Esc focuses the composer (no Tab → new tab). `ymz.useTerminal` falls back to the TUI launcher (`openTerminal` reuses; `openNewTerminal` always splits). Not Marketplace / no inline diff. [ADR-056](../../wiki/adr/056-vscode-webview-chat.md) · [ADR-054](../../wiki/adr/054-vscode-terminal-launcher.md). |
| **`/perm`** | `similar` / `permanent` no longer 500: grant TTL is **clamped** to the chat system approval window (start +24h). Empty-command process plans may issue a **command-narrowed** grant (`go test` prefix). Gateway maps `ErrNotApproved` / `ErrGrantDenied` to HTTP 400. [ADR-043](../../wiki/adr/043-tool-call-permission-interaction.md) · [ADR-046](../../wiki/adr/046-session-workspace-and-permission-tiers.md). |
| **Slash** | Webview `/cron` matches TUI: Go duration (`15m`, `1h30m`), `skill_ids`, `model_ref` (session prefer else main). Question cards need Esc Esc (3s) to dismiss. |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.7.0'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.7.0
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

**VS Code / Cursor** (VSIX on the same Release):

```bash
curl -fsSL -o ymz-vscode.vsix \
  "https://github.com/yyZe0122/YunmengZe-Agent/releases/download/v0.7.0/ymz-vscode_0.7.0.vsix"
code --install-extension ymz-vscode.vsix
```

Config root: **`~/.yunmengze`** · `ymz paths user` · `ymz config validate --mode user`.

## Notes

- TUI: `/quit` then `ymz tui` (or `ymz restart`) so the new binary loads.
- Idle Enter submits; running Enter steers. Steer 409 → new message.
- `/model` is this session; `/model main provider/model` is global.
- Tab Auto pre-grants process+git for **this session only**.
- Affiliate repos: `yyZe0122/homebrew-tap` (`Casks/ymz.rb`), `yyZe0122/scoop-bucket`.
