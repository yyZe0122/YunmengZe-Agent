# YunmengZe Agent v0.6.0

**Alpha · Pre-release**  
**Alpha · 预发布**

Session-scoped `/model`, permission and question cards, extra-root `/perm`, child-run resume, and product-facing config docs.

本会话 `/model`、提问/授权卡、工作区外 `/perm`、子代理续跑、以及产品向配置文档。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **`/model`** | Default is **this session**. Ready-page pick is a **sticky** TUI draft (`/new` does not clear it; every new session from ready writes `preferred_model` before `StartChat`). `/model main provider/model` is the global default. Removed `/model prefer`. TUI has no clear prefer (empty string only via `PATCH`). Ctrl+L / model picker Enter = this session. [ADR-045](../../wiki/adr/045-model-roles.md) · [ADR-053](../../wiki/adr/053-charm-v2-tui.md). |
| **TUI cards** | Question/permission **cards**: full prompt, numbered options, `Type your own answer`, multi-question ←→ wizard, multi-select Space. Esc Esc (3s) dismisses. Cards no longer steal Enter as steer. |
| **ask_user** | Custom answers allowed when options exist. `POST /v1/questions/{id}/dismiss`. Wait 30m. CLI/cron unavailable. |
| **`/perm`** | Extra-root for `fs_*` / process / git absolute paths: once (this call) · similar (session `extra_roots`) · permanent (`agent.local.json` `chat.workspace.allow`) · deny. Wait 30m. CLI/cron deny. Volume root `/` rejected. |
| **Sub-agent** | Explicit `task_id` resume (same child `run_id`); parent packing / TUI / `session_search` exclude child traces. Resume does not reverse `runs.state`; orphan `running` (no in-process runner) can be taken over. `ResumePrompt` appends after incomplete history. Pre-029 children (empty `child_kind`) cannot resume. [ADR-039](../../wiki/adr/039-logical-child-runs.md). |
| **Config / README** | Product-facing README (EN + ZH). Field table + OpenCode import map. Schema and example include `mcp.servers`. `import-opencode` maps allowed top-level `models.*` roles (drops `main` / unknown keys with warnings). Default `EnsureConfig` seeds `models.subagent` and `models.compact`. |
| **Prompt** | Interactive TUI: call tools and wait for `/perm`; do not tell the user to edit `agent.json`. |
| **Release** | Every tag **must** attach `ymz-vscode_{version}.vsix` (fail-closed; Node 18+). |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**


## Notes

- TUI: `/quit` then `ymz tui` (or `ymz restart`) so the new binary loads.
- Idle Enter submits; running Enter steers. Steer 409 → new message.
- `/model` is this session; `/model main provider/model` is global. Ready-page model pick sticks until you pick again (not across TUI restart).
- `/edit` hides the last turn; `/editundo` restores that turn’s files first. Rewind fail does not hide.
- Tab Auto pre-grants process+git for **this session only**.
- Affiliate repos: `yyZe0122/homebrew-tap` (`Casks/ymz.rb`), `yyZe0122/scoop-bucket`.
