# YunmengZe Agent v0.4.0

**Alpha · Pre-release**  
**Alpha · 预发布**

Xuan-paper TUI on Charm v2, VS Code terminal launcher, `/edit` retract, and `fs_remove` with typed file checkpoints.

清宣纸 TUI（Charm v2）、VS Code 终端启动器、`/edit` retract、以及带 `kind` 的 `fs_remove` 检查点。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **TUI chrome** | Charm v2 (`bubbletea` / `lipgloss` / `glamour` / `bubbles`). Xuan-paper chrome (few frames, no `░▒`). Braille brush on landing only. Compact header (1 row + hairline). Status under the editor. Hardware IME caret. Slash completion overlays the transcript bottom. [ADR-053](../../wiki/adr/053-charm-v2-tui.md). |
| **Tab** | Cycles **agent → plan → auto**. Idle Enter submits a new turn. Steer only while the current task is `running`; 409 falls back to submit. |
| **Todos / palettes** | `GET /v1/sessions/{id}/todos` pills (Ctrl+T). Ctrl+P command · Ctrl+L model · Ctrl+S session. |
| **`/edit`** | Hide last turn and fill the editor. `/editundo` rewinds that turn’s files first (`POST /v1/sessions/{id}/retract`). Shift+PgUp/Dn cycles sessions. Running spinner does not redraw completed bubbles. |
| **Files** | `fs_remove` deletes one regular file. `edit_revisions.kind`: create / modify / mkdir / delete (migration 028). Rewind restores deletes. [ADR-051](../../wiki/adr/051-coding-loop-contextview.md). |
| **Retract** | Clears that turn’s `transcript_search`, session todos, and compaction whose `through` lands on it. `agent_run_records` stay. Hidden tasks drop from transcript / ListTasks / GetTask / runs / session counts. |
| **IDE** | `extensions/vscode` opens the existing TUI in an integrated terminal. `make vscode`. Release uploads `ymz-vscode_0.4.0.vsix` (skip if Node missing). Not Marketplace. [Install](../../wiki/vscode.md) · [ADR-054](../../wiki/adr/054-vscode-terminal-launcher.md). |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.4.0'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.4.0
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

**VS Code / Cursor** (VSIX on the same Release):

```bash
curl -fsSL -o ymz-vscode.vsix \
  "https://github.com/yyZe0122/YunmengZe-Agent/releases/download/v0.4.0/ymz-vscode_0.4.0.vsix"
code --install-extension ymz-vscode.vsix
```

Config root: **`~/.yunmengze`** · `ymz paths user` · `ymz config validate --mode user`.

## Notes

- TUI: `/quit` then `ymz tui` (or `ymz restart`) so the new binary loads.
- Idle Enter submits; running Enter steers. Steer 409 → new message.
- `/edit` hides the last turn; `/editundo` restores that turn’s files first. Rewind fail does not hide.
- Tab Auto pre-grants process+git for **this session only**.
- Affiliate repos: `yyZe0122/homebrew-tap` (`Casks/ymz.rb`), `yyZe0122/scoop-bucket`.
