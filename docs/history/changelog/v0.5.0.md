# YunmengZe Agent v0.5.0

**Alpha · Pre-release**  
**Alpha · 预发布**

Typed sub-agents, web search, optional media tools, and models.dev window fill.

类型化子代理、网页检索、可选媒体工具、以及 models.dev 自动补窗。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **Provider** | Unset `contextWindow` fills from embedded [models.dev](https://models.dev) (`internal/modelcatalog`); miss → 1_048_576. Unset `maxTokens` omits `max_tokens` on OpenAI-compatible wires; Anthropic uses catalog or 128_000. Dropped the old `>16384 → 8192` packing clamp. OpenCode `limit.{context,output}` alias. Background refresh to `<ConfigDir>/cache/models.dev.json`. |
| **Sub-agents** | `task.kind` catalog (`general` / `explore` / `web`); children are always leaves (no nested `task`). Unknown/unadvertised kind and forbidden tool requests fail closed without spawning a run. `vision` / `speech` / `video` advertise only when the matching role is configured. [ADR-039](../../wiki/adr/039-logical-child-runs.md). |
| **Web** | `web_search` + `web_extract` (ddg default; searxng/tavily via `chat.web`). Interactive agent `/perm` (similar = host); plan/cron never advertise. SSRF exception only for configured SearXNG host on `web_search`. `models.web` whitelist; `task(kind=web)` advertised. |
| **Media** | ADR-055: `vision_analyze` (path or `/perm` url), `audio_transcribe` (Whisper multipart, not Complete), `video_analyze` (ffmpeg ≤8 frames). `models.vision`/`speech` whitelist. `task(kind=speech)` child Role is `subagent`. Input cap 16MiB. Main loop stays text. |
| **Prefix** | Lists extra configured `models.*` roles; no longer hard-codes “No vision”. |
| **Docs** | Product README sells S/W/M + catalog fill. Example config adds `models.web`. |

### 中文摘要

| 区域 | 变更 |
| --- | --- |
| **Provider** | 省略 `contextWindow` 从 models.dev 填窗；省略 `maxTokens` 则兼容协议不发；接受 OpenCode `limit.{context,output}` |
| **子代理** | `task.kind`：`general` / `explore` / `web`；子永远叶子；配了 role 才有 vision/speech/video |

| **媒体** | `vision_analyze` · `audio_transcribe` · `video_analyze`；主循环仍是文本 |
| **文档** | README 卖点与示例配置对齐 |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.5.0'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.5.0
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

**VS Code / Cursor** (VSIX on the same Release):

```bash
curl -fsSL -o ymz-vscode.vsix \
  "https://github.com/yyZe0122/YunmengZe-Agent/releases/download/v0.5.0/ymz-vscode_0.5.0.vsix"
code --install-extension ymz-vscode.vsix
```

Config root: **`~/.yunmengze`** · `ymz paths user` · `ymz config validate --mode user`.

## Notes

- TUI: `/quit` then `ymz tui` (or `ymz restart`) so the new binary loads.
- Idle Enter submits; running Enter steers. Steer 409 → new message.
- `/edit` hides the last turn; `/editundo` restores that turn’s files first. Rewind fail does not hide.
- Tab Auto pre-grants process+git for **this session only**.
- Affiliate repos: `yyZe0122/homebrew-tap` (`Casks/ymz.rb`), `yyZe0122/scoop-bucket`.
