# YunmengZe Agent v1.0.1

**Stable release · 正式版**

This release adds startup switches for optional capabilities, improves credential error reporting and fixes cancellation, session leases and preference expiry. It also includes the module review, removal of unused code, and updated English/Chinese READMEs and wiki pages.

本版增加可选能力的启动开关，改进凭据错误提示，修复取消、会话租约和偏好过期处理，并整理分模块 review、确定无用的代码及双语 README / Wiki。

## Highlights

- **Explicit optional capabilities.** Skills, memory, child tasks, web, vision and MCP have independent startup switches, enabled by default. Disabled capabilities skip initialization and tool registration; disabling skills also skips discovery and expansion. Web child tasks follow the web switch. Existing data is preserved.
- **Configuration and credential snapshots.** Startup records resolved credentials and their errors together. The main model and enabled-capability dependencies must be available; an invalid optional model is reported as unavailable without blocking unrelated work. Provider adapters receive resolved keys directly. `ymz config validate` and the TUI show availability information.
- **Clearer module boundaries.** Optional capabilities have explicit Engine composition files. Frontends call application operations instead of accessing session or memory stores directly. Memory receives transcript evidence through an interface, providers no longer depend on tools, and web tools receive their own configuration values. Further architectural changes remain proposals in the review backlog.
- **Cancellation and compaction fixes.** Cancellation interrupts blocked MCP stdio exchanges and closes the affected connection. Manual compaction renews and releases the session lease, and a cancelled native-compaction request does not start a fallback request. Context packing accounts for image content when reclaiming older tool results while preserving the stored transcript.
- **Preference expiry.** Naturally expired preferences can be learned again from newer evidence. Explicit forgetting and existing archives continue to prevent automatic recovery; user corrections refresh the preference expiry.
- **Focused cleanup and documentation.** Remove unused configuration loaders, obsolete context splitting and memory write APIs, and redundant internal guards. Retain relevant business tests and adapt existing callers to current APIs. Align both READMEs, the wiki and contributor guidance with the implementation, retain copyable Scoop/Homebrew installation commands, and record outstanding review findings separately.

- 启动时同时快照凭据和解析错误，只要求主模型及已启用能力的依赖可用。其他无效模型会标为不可用，选择时明确报错；配置校验和 TUI 显示相应状态。

## Upgrade from v1.0.0

No database migration is added or changed in v1.0.1. Existing configurations keep optional capabilities enabled unless explicitly disabled. The switches are `chat.skills.enabled`, `chat.memory.enabled`, `chat.task.enabled`, `chat.web.enabled`, `chat.vision.enabled` and `mcp.enabled`. `chat.compaction.enabled` controls automatic compaction only. Restart `ymz` after configuration or credential changes.

v1.0.1 没有新增或修改数据库迁移；原有配置默认继续启用可选能力。通过上述开关按需关闭能力，`chat.compaction.enabled` 仅控制自动压缩。配置或凭据修改后需要重启 `ymz`。

See the versioned [configuration reference](https://github.com/yyZe0122/YunmengZe-Agent/blob/v1.0.1/docs/wiki/configuration.md) and [module review backlog](https://github.com/yyZe0122/YunmengZe-Agent/blob/v1.0.1/docs/backlog/current.md). The ten outstanding review findings are documented follow-up work, not fixes included in this release.

配置说明和分模块审核详见以上版本化文档；review 中的 10 项问题仍是待办，本版未宣称完成这些修复。
